Les deux bancs E2E

Chaîne signaux → zones → lots (banlieues de Montréal). Difficulté centrale : le rapprochement signaux↔zones — 14/30 villes citent une zone ; rappel ~60 % (proxy) / 47–59 % (55 villes). Causes : libellés de zones des PV vs codes servis ; non-matchs attendus (zones proposées).

Delson, Sainte-Catherine, Saint-Constant, Candiac : l'expérience produit (lots/zones, filtres, fiche lot) confrontée à l'application de référence du partenaire. Ex. : dérivation « 4+ logements » à 97,5 % d'exactitude sur 3171 lots.

Graphes & signaux

Qualité avant volume

Deux versions d'ontologie

  • v2.2 — entités correctes mais grounding partiel (citation parfois absente, ou pointant un document introuvable).
  • v2.3 — citation vérifiable obligatoire (page/passage verbatim du PV réel) + gates de publication qui rejettent toute citation non substantiée.
  • v2.2 → v2.3 = durcissement de la preuve : moins de signaux publiés, chacun traçable jusqu'au document.

Le PV scrapé (recueil brut, 27/30 · ~1007/1104) est le substrat ; les signaux en sont extraits — le graphe est la méthode de parsing, pas la finalité.

978 / 1104
signaux extraits v2.3 — focus 25 / 30 effectif

Reliquat 128 villes = ~30 v2.2 à re-grounder + ~97 sans aucune donnée brute (scraping préalable).

Citation vérifiable = 100 % attendu

Focus 56 / 70 signaux à citation vérifiable → les 14 restants passent en cleansing : re-grounder depuis le PDF réel, ou purger si non substantiable. La cible n'est pas « 80 % », c'est 100 % — un signal sans citation vérifiable ne doit pas être présenté.

  • Sources pilotées par configuration, un scraper générique.
  • Fournisseurs OCR / LLM interchangeables ; projection rejouable.
  • Couches d'identité OAuth réversibles (app + connecteur MCP) sans toucher au domaine.

  • Preuve PDF : archive objet sondée d'abord, repli sur store de métadonnées.

Utilisation de l'IA

Mixture of agents

Le mécanisme central est le consensus multi-agents : un agent produit, un autre relit / arbitre (vérification adverse, doubles comptes) — il attrape les erreurs qu'une seule passe laisserait passer.

Un produit, un relit : le consensus croise les points de vue sur les décisions difficiles. Gates déterministes pour publier ; métriques & citations pour arbitrer ; humains pour valider le métier.

Exploitation & coûts

Industrialiser en maîtrisant les coûts

Coût au siège

Runs ciblés, focus 30, premium sur les cas durs. Coût d'une preuve, maîtrisé.

Coût complet

1104 villes, refresh, OCR, stockage, LLM, supervision. Coût d'un service, dominé par les volumes récurrents.

  • Premium réservé aux cas à forte valeur ; transformations déterministes ailleurs.
  • Batcher les villes, borner les extractions, jobs incrémentaux (hashes, fraîcheur).
  • Unité économique = signal vérifiable produit, pas le token brut.
  • CronJobs de refresh suspendus (FinOps) : job défaillant réveillait un pool de calcul → suspend:true jusqu'au fix.

Chiffrage détaillé (immo LLM/infra · geo · geo-quebec) en attente — relevés agent-stats, k8s et geo demandés, format aligné facturation.
