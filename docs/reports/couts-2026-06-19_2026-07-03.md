### A.2 Dérivation de la facture SCW (infra)

Sources (mesures du 2026-07-03) :

- **Facturation réelle** : `scw billing consumption list project-id=<PoCs> billing-period=2026-06|2026-07`. Projet PoCs (le cluster + services associés) : **juin 407,81 €** (dont nœuds/instances « Compute » **247,93 €**) ; **juillet MTD 01→03 : 33,76 €** (dont nœuds 22,79 €).
- **PVC** : `kubectl get pvc -A` ; tarifs SCW : block `sbs` 0,0949 €/Gi/mois, File System facturé réel.
- Les messages h2a de poc-k8s (`env:pock8s:radar-geo-costs`) sont **introuvables sur disque** (aucun `.h2a` dans poc-k8s, aucune occurrence de « radar-geo-costs ») → les chiffres ci-dessus sont pris **à la source** (billing + kubectl), ce qui est plus fiable qu'un relais de message.

Coût des nœuds sur la période (15 j) : nœuds période = juin Compute × 12/30 _(lissage mensuel, estimé)_ + juillet MTD (réel) = 247,93 × 0,4 + 22,79 = **121,96 € ≈ 197 CAD**.

### A.4 Contexte du prorata — plateforme partagée (sentropic), hors postes client

sentropic est l'outillage mutualisé (harness, agent-stats, track, h2a, design system, poc-k8s…) au service des deux produits. Ses coûts **ne sont pas des postes client** ; ils figurent ici parce que le prorata des coûts partagés exige de mesurer l'usage des **3** comptes — sans ce dénominateur commun, les parts immo/geo seraient faussées.

| (A) Infra k8s | ~22,9 CAD (nœuds 7,07 € → 11,4 CAD + block 0,2 CAD + **FS RWX 93 Gi : 11,2 CAD**, facturé réel : 13,44 € juin × 12/30 + 1,55 € juil) |

| **Total période** | **~73,6 CAD** |

- Totaux toutes parts (3 comptes), en référence : **LLM 105,76 CAD · infra ~33,8 CAD · ~139,6 CAD** (LLM : 16,64 Md claude, 33,2 % + 0,63 Md codex, 0,8 % ; prorata 67,12 USD → 91,96 CAD ; ~1,5 h interactif).

Cette borne sur-attribue (immo/geo tournent aussi sur ces nœuds) ; la clé officielle du rapport reste l'usage réel, cohérente avec les semaines précédentes — et elle est **neutre pour immo/geo** (leur part reste calculée sur leur propre usage).
